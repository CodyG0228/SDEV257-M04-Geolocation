# Geolocation Expo app

This is a plain Expo/React Native project using `index.js` and `App.js`, similar to a standard JavaScript Expo project.

## Get started

```bash
npm install
npm start
```

Use Expo Go or a simulator to run the app.

Edit [App.js](./App.js) to update the app and [styles.js](./styles.js) for its styles.
